## Repository Overview
- Project name: warawara
- ブラウザーで遊べるシンプルなゲーム
- Primary language: JavaScript/HTML5 (browser-based game)

## Key Directory Structure
- `web/` - The game itself: `index.html` + `web/src/` (ES module source). This is the single source of truth for game logic, shared unchanged between the plain browser build and the Tauri desktop build.
- `src-tauri/` - Tauri v2 desktop app wrapper (Rust). Points `frontendDist` at `../web`. See "Desktop app (Tauri)" below and [CLAUDE.md](CLAUDE.md) for full build instructions.
- `test/` - Test files (currently empty — no test suite configured)
- `docs/` - Documentation, including a dev-session log

## Desktop app (Tauri)

This project is being turned into a standalone desktop app (Windows/macOS/Linux) using **Tauri v2**, chosen over Electron/a native rewrite because it wraps the existing web code unchanged, produces a much smaller/lighter binary, and — unlike Electron — Tauri 2.0 also supports Android/iOS from the same codebase, which is relevant since mobile is a likely future direction for this project.

- **Status**: macOS and Windows builds both working end-to-end (`cargo tauri dev` and `cargo tauri build` both produce a working app on each; see [CLAUDE.md](CLAUDE.md) for commands). Windows produces both an MSI and an NSIS installer under `src-tauri/target/release/bundle/`. Linux build has not been done yet — it requires running the build on (or via CI for) that OS; see CLAUDE.md's per-OS prerequisites before starting.
- **Important**: `src-tauri/target/` is a multi-GB, OS/arch-specific Rust build cache. This repo is currently synced via Synology Drive (no git repo yet), so nothing auto-excludes it by default — it has been added to Synology Drive's sync-exclude list on both the macOS and Windows machines currently used for development; do the same on any new machine, or set up git and rely on `src-tauri/.gitignore` (already generated by Tauri).
- Full build/run commands and per-OS prerequisites (Rust toolchain, platform-specific packages) are documented in [CLAUDE.md](CLAUDE.md) — read that before setting up a new machine.

## Game Requirements
- 画面サイズは正方形を原則にします。
- 画面サイズは、ウィンドウサイズに合わせる形で正方形にします。
- マウスカーソルの位置に、自身のキャラクター（主人公と呼ぶ）を配置します。
- マウスの動きに合わせて主人公を動かします。
- 秒単位で時間をカウントし、30秒経過すると敵キャラクターが出現します。
- 敵キャラクターは画面の四隅のいずれかから現れ、一定のスピードで主人公に向かって移動します。
- 敵キャラクターは、慣性の法則に従って移動します。
- 敵キャラクター同士は、衝突判定があります。
- 敵キャラクター同士がぶつかると、物理法則に応じて反射します。
- 主人公と敵キャラクターが衝突したら、ゲームオーバーです。
- ゲームをスタートしてから、ゲームオーバーまでの時間が、得点になります。
